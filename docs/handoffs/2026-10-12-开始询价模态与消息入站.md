# 开始询价模态与消息入站（2026-10-12）

安琳定的口径。开始询价不再只改列表状态。采集到的真实消息要进系统记录和页面。

## 1. 开始询价

点「开始询价」只打开模态框，不调用原来的 `/api/rfq/start`，也不把债券标成「询价中」。

模态框左侧是已选的每一只债，右侧是当前配置企点号的通讯录。通讯录来自 `data/address_book.json` 里这个 `workbench_id + account_uid` 的好友和组织架构，不读南银存款的微信群。

每一只债先填这些字段，再按下面的两行文字发出：

| 字段 | 示例 |
|---|---|
| 价格 `price` | 2.17 |
| 交易方向 `side` | ofr |
| 剩余期限 `tenor` | 4.98Y |
| 市场代码 `code` | 032680366.IB |
| 债券简称 `name` | 26安吉两山PPN002 |
| 公私募 `placement` | 私募 |
| bid | 空则写成 `--` |
| ofr | 2.1700 |
| bid 量 `bid_vol` | 空则写成 `--` |
| ofr 量 `ofr_vol` | 空则写成 `--` |
| 票面 `coupon` | 2.14% |
| 主体评级 `issuer_rating` | AA+ |
| 债项评级 `bond_rating` | 空则写成 `--` |
| 中债推荐估值 `cnbd` | 2.1763 |
| 余额 `balance` | 13.00亿 |
| 到期日 `maturity` | 2031-06-26 |
| 经纪商 `broker` | 上田 |
| 报价时间 `quoted_at` | 09:00:34 |

渲染结果，字段之间是两个空格：

```
2.17*ofr
4.98Y  032680366.IB  26安吉两山PPN002  私募  --/2.1700  --/--(*)  票面2.14%  AA+/--  中债2.1763  余额13.00亿  到期日2031-06-26  上田  09:00:34
```

一条报价可以勾多个人。多条报价勾了同一个人时，发送前把这些报价用换行拼成一条。没勾人的报价不能发。确认之后才写公网信箱指令。指令被红线闸拦住或工作台未上报时，不能把该债标成「询价中」。

测试用合成债券和合成 uin，不向真实企点号发消息。

## 2. 接口

`POST /api/im/rfq/send`

请求：

```json
{
  "items": [
    {
      "code": "032680366.IB",
      "fields": {
        "price": "2.17",
        "side": "ofr",
        "tenor": "4.98Y",
        "name": "26安吉两山PPN002",
        "placement": "私募",
        "bid": "",
        "ofr": "2.1700",
        "bid_vol": "",
        "ofr_vol": "",
        "coupon": "2.14%",
        "issuer_rating": "AA+",
        "bond_rating": "",
        "cnbd": "2.1763",
        "balance": "13.00亿",
        "maturity": "2031-06-26",
        "broker": "上田",
        "quoted_at": "09:00:34"
      },
      "uins": ["9102001"]
    }
  ]
}
```

响应：

```json
{
  "ok": true,
  "data": {
    "batches": [
      {"uin": "9102001", "text": "渲染并换行合并后的正文", "status": "submitted", "cmd_id": "…"}
    ]
  }
}
```

同一个人的多只债只出现一批。`text` 是渲染结果用换行接起来。没有收件人、字段缺市场代码或简称时返回 400，不写指令。

## 3. 消息入站

配置的是哪个号，页面就只看那个号。

- 询价：公网模式下机器人监控要显示采集库里 `self_uid` 等于当前企点号的消息。415011447 发给 3007378246 的记录如果已经在采集库，监控必须能打开这条会话。不在采集库，就查 OSS 询价出站对象，把拉到的消息写入询价自己的记录再显示。不要造演示对手。
- 南银存款：微信群消息只走该微信号的 `groups.json` 和已选群。进现有消息表，并进入现有 Dify 队列。企点通讯录不进存款。
