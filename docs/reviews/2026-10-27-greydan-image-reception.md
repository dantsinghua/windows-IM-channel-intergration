## 5. 整改后的验收标准

| 场景 | 必须取得的证据 |
|---|---|
| 新入站图片与采集账号自发图片 | 各自原生 seq、正确当前账号、非空媒体引用、可解码原图、完整自动传输与解析；方向不能成为内容过滤条件 |
| 同图重复发送 | 每条原生消息身份独立，媒体可按内容去重；所有 media ID 仍可读，不能丢附件、重复解析同一事件或误合并不同消息 |
| 大图、缩略图及分块 | 明确选择原图/缩略图，记录实际字节数与 SHA；超过内联阈值验证分块重组及摘要，不用缩略图冒认原图 |
| 引用缺失、404、损坏或解密失败 | 明确错误与可控重试，不产生空附件“成功”，不降级为纯文本并声称视觉解析成功 |
| 历史空媒体记录 | 按定点补全方案核前像、消息身份、关联更新、去重及原发送状态保护 |
| UNKNOWN 并存 | 采集事实与发送归属分别验收；旧 UNKNOWN 不被改写，授权和人工接管规则仍成立 |
| Dify/shim | 原生图字节 SHA → 附件或分块 SHA → ODS image_hash → 节点1003文件输入 → shim带图 → 上游视觉结果同次对应；记录模型实际识别内容，不只核调用状态 |
