# 审计 · 无大模型(安琳 A-1,2026-09-18)

> 依据:`00-共享基线与口径.md` §11.11 / §14 A-1——**除 `voice_to_text` 的 ASR 外,本程序不使用任何大模型/agent 能力;只做消息采集、消息发送,编排固定**。读取三级 = frida → 控件树 → **截图 + 离线传统 OCR 引擎**(不是多模态转录)。
> 扫描范围:主文档 `DESIGN-多实例控制台与统一RPA.md` + `design/01~06` 六册。关键词:`大模型|LLM|多模态|VLM|GPT|Claude|智能|agent 能力|自然语言|prompt|转录|OCR|识别|ASR|asr_provider|拒答`。
> 判定:① ASR(保留);② 用大模型读消息(改离线 OCR);③ 编排/路由被说成智能决策(改固定规则);④ 普通用词(不动)。行号为**改后**行号。

## 3. 结论

**「除 ASR 外零大模型」成立**:全部七册里,大模型的唯一接入点是主文档 A.4 / 02 §7.1 `[asr]` / 01 §2.7.10 ASR 设置 / 06 §2.10 `asr_*` 字段——即 `voice_to_text` 一条链路;原先唯二写成「多模态转录」的读消息路径(主文档 §5.3 第 2 级与 A.3 三级降级)已改为「截图 + 离线传统 OCR 引擎(PaddleOCR 离线包,随 rootfs 打包不出网)」并配 `[ocr]` 配置段与数字/金额误差对策(与控件树/frida 交叉校验、低置信标 `needs_review` 交人工);编排(§5.4)自始就是固定工作流描述,无智能决策措辞;03/04 两册零大模型相关内容。
