;!@Install@!UTF-8!
; ============================================================================
;  QTrade 自解压外壳(7-Zip SFX)配置 —— docs/03 §2.1
;
;  外壳只做一件事:把归档解到 %ProgramData%\QTrade,然后拉起里面的安装引擎。
;  它**不弹自己的向导**(GUIMode=2 静默解压 + 进度条)、**不写注册表**、**不判环境**——
;  环境判断在引擎 PRECHECK 里,SFX 阶段只可能因**磁盘不够**失败。
;
;  🔴 解压目录写死 %ProgramData%\QTrade(-o 等价物 InstallPath),用户不可选:
;     载荷路径被 .wslconfig / 服务 / 计划任务写死(§2.1、P0-12)。
;  🔴 引擎退出码**原样透传**为 EXE 退出码(§2.1 表);引擎用 kernel32 ExitProcess 设置。
;
;  ⚠️ 本文件按 **7zSD.sfx**(扩展版 SFX 模块)的键写。stock `7zS2.sfx` 不认 InstallPath/RunProgram。
;  ⚠️ 已知偏差(见 .omc/handoffs/installer.md「建议裁决」#1):§2.1 要求「SFX 解压**前**判一次目标盘
;     可用空间(< 6 GB 退 26)」,但 7zSD.sfx 的 ExecuteFile/RunProgram 都在**解压之后**才执行,
;     模块本身没有 pre-extract 钩子。本配置把 precheck-disk.cmd 放在 RunProgram 链首,
;     做到「引擎跑之前」判断;要做到「解压之前」判断须重编 SFX 模块或改用 WiX Burn 外壳(§2.1 备选行)。
; ============================================================================

Title="QTrade 安装程序"
BeginPrompt=""
Progress="yes"
GUIMode="2"
InstallPath="%ProgramData%\\QTrade"
OverwriteMode="2"
ExtractTitle="QTrade"
ExtractDialogText="正在解压 QTrade 安装文件,请稍候…"
ExtractPathText="解压到"
ExtractPathTitle="QTrade"
ExtractCancelText="取消"
; RunProgram 链首是磁盘粗判(< 6 GB 退 26),它再以同样的参数拉起引擎
RunProgram="install\\engine\\precheck-disk.cmd"
GUIFlags="8+32+64"
;!@InstallEnd@!
